# FRC2026

The code for the Chargers' 2026 robot, Wasabi.

### Important Folders
- /src/main - RIO robot code
- /scripts - python utilities, including vision recording and path mirroring
- /advantagescope-assets - Common assets folder for 3d models/layout

### How to Run: IntelliJ
To the left of the run button, there should be a dropdown. From there,
you can run "Simulate Code", "Deploy Roborio", and "Replay Log File"

### How to Run: WPILib VScode
Press Ctrl+Shift+P, then search for "simulate java" and "deploy robot code"
for running code in sim and the real robot, respectively. For replay, search
for "run tasks", select it, and click the appropriate replay task.
